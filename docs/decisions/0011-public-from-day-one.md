# 0011. Build in public from day one

- Status: Accepted
- Date: 2026-10-10

## Context

A security tool earns trust by being auditable. An early public repo costs nothing, collects stars that help Marketplace ranking, and lets experts comment on the design before launch. The risk is showing unfinished work.

## Decision

The repository is public from creation. The README states the pre-alpha status plainly, and the launch in mid-December 2026 (launch week from Tue Dec 8) is the first time Garnet is promoted.

## Consequences

Design docs, the threat model and early mistakes are visible. Novel detection bypasses still go through private reporting (SECURITY.md).
